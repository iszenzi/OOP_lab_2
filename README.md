# Лабораторная работа № 2: класс Polynomial

**Вариант 11. Семейство B — многочлены**

Консольная программа хранит многочлен в динамической памяти, вычисляет его значение,
складывает и умножает многочлены, находит корень методом бисекции.
Используются C++20, классы, RAII, копирование и перемещение, ручное управление памятью
через `new[]` и `delete[]`. `std::string`, стандартные контейнеры и умные указатели
не используются в реализации класса и консольной программе.

## Задание варианта

- `find_root` ищет корень многочлена методом бисекции на отрезке `[a, b]`.
- Отрезок последовательно делится пополам; сохраняется половина с разными знаками значений на концах.
- Поиск завершается, когда модуль значения многочлена в найденной точке меньше `1e-9`.

Пример для многочлена x² − 2:

```text
Коэффициенты: -2 0 1
Отрезок: 1 2
Корень: 1.41421356238
```

Коэффициенты задаются от свободного члена к старшему: элемент с индексом `i` соответствует x^i.
Массив `[3, 2, 5]` представляет 3 + 2x + 5x².
Завершающие нулевые коэффициенты удаляются; у нулевого многочлена степень равна `-1`,
указатель на буфер равен `nullptr`.

## Объявленные методы

| Объявление | Назначение |
| --- | --- |
| `Polynomial()` | Создание нулевого многочлена. |
| `Polynomial(const double* coeff, int degree)` | Независимая копия массива коэффициентов с нормализацией степени. |
| `Polynomial(const Polynomial& other)` | Глубокое копирование многочлена. |
| `Polynomial(Polynomial&& other) noexcept` | Передача буфера за O(1); источник становится нулевым многочленом. |
| `~Polynomial()` | Освобождение динамического массива. |
| `Polynomial& operator=(Polynomial other)` | Присваивание через copy-and-swap; аргумент создаётся копированием или перемещением. |
| `void swap(Polynomial& other) noexcept` | Обмен буферами и степенями. |
| `int degree() const` | Степень многочлена; для нулевого — `-1`. |
| `double evaluate(double x) const` | Вычисление значения по схеме Горнера. |
| `void add(const Polynomial& other)` | Прибавление другого многочлена с нормализацией результата. |
| `void mul(const Polynomial& other)` | Умножение на другой многочлен с нормализацией результата. |
| `void print(std::ostream& out) const` | Вывод в переданный поток без перевода строки. |
| `double find_root(double a, double b) const` | Бисекция с проверкой порядка границ, знаков и точности. |

Закрытый метод `trim()` удаляет старшие нулевые коэффициенты и уменьшает буфер.

Условия использования:

- Конструктор из массива принимает неотрицательную степень и действительный массив минимум из `degree + 1` элементов.
- Входной массив не принадлежит объекту: конструктор создаёт собственную копию.
- Консольный ввод принимает только конечные числа; вычисления выполняются в типе `double`.
- Сложение и умножение изменяют текущий объект, сохраняя другой; допустимы `p.add(p)` и `p.mul(p)`.
- Для поиска корня требуется `a < b`. Если модуль значения на конце меньше `1e-9`, возвращается этот конец.
- В остальных случаях значения на концах должны иметь разные знаки. Иначе возникает `std::invalid_argument`.
- Если за 1000 итераций точность не достигнута, возникает `std::runtime_error`.
- Для нулевого многочлена на корректном отрезке возвращается левая граница: значение равно нулю в каждой точке.

## Меню программы

```text
1. Ввести многочлен
2. Напечатать многочлен
3. Показать степень
4. Вычислить значение
5. Прибавить многочлен
6. Умножить на многочлен
7. Найти корень на отрезке
0. Выход
```

Изначально хранится нулевой многочлен. При вводе задаются степень от **0 до 100**
и коэффициенты от свободного члена к старшему. Нулевые коэффициенты допустимы.
При сложении и умножении программа запрашивает второй многочлен и печатает результат.

Ошибочный числовой ввод, неверный пункт меню и некорректный отрезок поиска сопровождаются сообщением.
При неуспешном вводе многочлена прежнее значение сохраняется.
При конце ввода программа завершает работу; память освобождается деструкторами.
Ошибка выделения памяти также обрабатывается.

## Сборка и запуск

Требуются GNU GCC с поддержкой AddressSanitizer и CMake версии 3.20 или новее.
На Windows команды выполняются в Ubuntu WSL из папки проекта.
Если Google Test отсутствует в системе, CMake скачивает версию `v1.15.2`; для этого нужен интернет.

Первоначальная настройка:

```bash
cmake -S . -B build/debug -DCMAKE_BUILD_TYPE=Debug
```

Сборка и запуск:

```bash
cmake --build build/debug && ./build/debug/lab02_main
```

Запуск тестов:

```bash
ctest --test-dir build/debug --output-on-failure --no-tests=error
```

CMake собирает общую библиотеку `lab02_lib`, программу `lab02_main` и тестовый исполняемый файл `tests`.
Программа и тесты используют одну библиотеку; `main.cpp` не входит в тестовую цель.
AddressSanitizer включён при компиляции и линковке во всех конфигурациях, включая Release.

## Тестирование

В проекте **23 теста Google Test**.
Проверяются создание, нормализация, копирование, перемещение, присваивание, самоприсваивание,
обмен, вычисление значения, сложение, умножение, нулевые многочлены и вывод.
Для бисекции проверяются положительный и отрицательный корни, корни на концах,
неверный порядок границ, одинаковые знаки и недостижимая точность.
Порог `1e-9` взят из условия варианта и проверяется по модулю значения в найденной точке.

Обычные проверки объединены в набор `PolynomialTest`, ожидаемые исключения — в `PolynomialTest_Throw`.
Оба набора должны проходить. CTest запускает тесты с проверкой утечек памяти через ASan.
В тестах вывода используется `std::ostringstream`; класс `Polynomial` и программа его не используют.
